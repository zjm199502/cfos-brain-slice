# FosFolio 软件内更新

打开「帮助 → 检查更新 → 现在更新」，然后重启。软件会按本机已安装的系列应用补丁。

| 「帮助 → 关于」显示的当前版本 | 重启后的版本 | 手动下载 |
| --- | --- | --- |
| v0.8.x（StarDist） | v0.8.11（StarDist） | [v0.8.x 专用下载页](v0.8/README.md) |
| v0.9.x（Cellpose 4） | v0.9.2（Cellpose 4） | [v0.9.2 专用补丁](https://raw.githubusercontent.com/zjm199502/cfos-brain-slice/installers/updates/v0.9/cfos-patch-0.9.2.zip) |

旧客户端的检查窗口共用一个标题，首次可能显示 v0.9.2。v0.8.x 安装版会自动选用 v0.8.11。手动安装时，在「帮助 → 从文件安装补丁…」中直接选择对应系列的 ZIP。[更新公告](更新公告.md)
