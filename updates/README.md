# FosFolio 软件内更新

## 当前版本 0.9.19

已安装 0.9.x 的用户可打开「帮助 → 检查更新 → 现在更新」，安装累计补丁后重启。

使用 0.7 或 0.8 运行环境的用户，请先安装 [Windows x64 基础版](https://github.com/zjm199502/cfos-brain-slice/releases/download/v0.9.0/FosFolio-0.9.0-Windows-x64-Setup.exe) 或 [Apple 芯片 Mac 基础版](https://github.com/zjm199502/cfos-brain-slice/releases/download/v0.9.0/FosFolio-0.9.0-macOS-arm64.zip)，再在软件内检查更新至 0.9.19。[0.9.19 累计补丁](https://raw.githubusercontent.com/zjm199502/cfos-brain-slice/installers/updates/v0.9/cfos-patch-0.9.19.zip)

继续使用 StarDist 0.8 系列的用户可安装 [0.8.12 兼容补丁](https://raw.githubusercontent.com/zjm199502/cfos-brain-slice/installers/updates/v0.8/cfos-patch-0.8.12.zip)。此补丁提供「帮助 → 升级至 FosFolio 0.9.19…」入口。
