## 2026-11-27 · FosFolio 1.0.0

FosFolio 1.0.0 面向 Windows x64 和 Apple Silicon Mac，内含 Cellpose 4 运行环境与模型。

- 修复旧项目细胞坐标触发的共标统计错误。先前因 hypot 报错而跳过的图片可按原参数重跑，已有且匹配的脑片识别缓存会被复用。
- 旋转脑片后，左键拖动视野会跟随鼠标在屏幕上的实时方向。
- 优化大量细胞标记显示时的缩放和鼠标定位，保留人工校正与细胞计数。

请先保存项目并退出软件。Windows 用户从腾讯云下载完整 ZIP，解压后运行 Setup.exe；从 GitHub 下载时，将 Setup.exe、-1.bin、-2.bin 放在同一目录再安装。Apple Silicon Mac 用户请解压 .tar.xz 并将其中的应用程序安装到“应用程序”。

国内优先使用腾讯云 CNB：https://cnb.cool/fosfolio/cfos-brain-slice/-/releases/tag/v1.0.0
GitHub 备用：https://github.com/zjm199502/cfos-brain-slice/releases/tag/v1.0.0
