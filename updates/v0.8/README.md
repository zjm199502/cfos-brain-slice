# FosFolio v0.8.x（StarDist）

已安装 v0.8.x 时，打开「帮助 → 检查更新 → 现在更新」，然后重启。进入「帮助 → 关于」可核对版本为 v0.8.11。旧检查窗口第一次可能把共用入口显示为 v0.9.2，软件会按本机安装版本选择 v0.8.11。

如果旧窗口提示「需要下载完整安装包」，请关闭该窗口。下载 [v0.8.11 专用补丁 ZIP](https://raw.githubusercontent.com/zjm199502/cfos-brain-slice/installers/updates/v0.8/cfos-patch-0.8.11.zip)，在「帮助 → 从文件安装补丁…」中直接选择该 ZIP，然后重启。这也是手动更新的方式。

完成后打开「⑧ 导出 Excel → 脑区范围 → 自选脑区…」，按名称、缩写或 Allen ID 搜索，勾选后点击「应用」。[v0.8.11 更新公告](更新公告.md)

### 重新安装 v0.8 基础版

- Windows 用户可下载全部安装包分卷，放入同一目录，按原包说明合并后安装。[Windows v0.8 文件](../../windows)
- Apple 芯片 Mac 用户可下载全部压缩包分卷并合并后安装。[macOS v0.8 文件](../../mac)
