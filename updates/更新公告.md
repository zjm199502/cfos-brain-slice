# FosMap 脑片活动图谱 更新公告（原名 cFos 脑片分析）

## v0.8.3（2026-11-15）

# v0.8.3 更新内容（小更新）

## 推荐主指标：X+ 占 DAPI+ 的比例
- 导出的 Excel“按脑片汇总”“按脑区×脑片”（以及“按自定义区域”）新增“X+ 占 DAPI+ 的比例 %”，例如“Red+ 占 DAPI+ 的比例 %”。分子只算有细胞核（DAPI+）的 X+ 细胞，分母是同一张脑片、同一个脑区里的 DAPI+ 细胞。
- 这个比例不受切片厚度、组织收缩和脑区面积误差的影响，不同动物之间更好比较，推荐作为主要指标；原来的密度（个/mm²）仍然保留，作为补充。
- “⑦ 分组与统计”“脑区活动与行为相关”“功能网络”的指标下拉框里，这一项排在最前面，新项目默认就用它。按动物统计时，先把同一只动物所有脑片的细胞数加起来，再算比例（不是把各脑片的比例取平均）。
- 新增“比例提示”列：DAPI+ 不到 200 个的区域，以及细胞特别密、DAPI 容易少识别的脑区（齿状回、CA1–CA3 锥体层、嗅球颗粒层、小脑皮层等），会标出“DAPI 可能偏少，比例偏高”，看结果时要留意。
- 示例脑片：Red+ 占 DAPI+ 的比例为 52.9%。

## 自己选每个通道的显示颜色
- “③ 亮度 / 对比度”里每个通道多了“显示颜色”：可以选蓝、绿、红、品红、黄、青、白，或点“自定义…”用调色板选任意颜色。看图窗口、质控图、截图制图、配准图导出都用这个颜色；只改显示，不影响识别和统计。
- 新建项目时，显示颜色默认沿用显微镜软件里存的颜色（例如显微镜把 Far Red 存成黄色，就显示成黄色），和在显微镜软件里看到的一样。选“默认（按染色）”可以回到 DAPI 蓝、Green 绿、Red 红、Far Red 品红。
- 以前的项目打开后颜色不变。

## 通道不会因为显示颜色特殊而认错
- 加入图片时判断每个通道是 DAPI / Green / Red / Far Red，现在先看通道名里的染料或波长（DAPI、Hoechst、488、520、594、620、647、670、Cy3、Cy5 等），文件里存的显示颜色只作最后参考。
- 以前 qptiff 是按文件里存的颜色判断的：显微镜把 Far Red 存成黄色时，这个通道认不出来，只能在“② 脑片拆分”里手动改。现在只要通道名里有染料或波长就能自动认对。
- 通道名里既没有染料也没有波长时（如“通道 3”），仍需要在“② 脑片拆分”的下拉框里手动选。

## 脑区平均荧光强度也去除串色
- 在“④ 细胞识别”里开启了“识别前去除通道串色”时，导出 Excel 时勾选的“统计每个脑区的平均荧光强度”，现在也按去除串色后的图计算，和细胞识别、细胞亮度的口径一致。没开启串色校正时和以前完全一样。
- 做法是每块图读出来后先逐个像素去除串色，再按脑区求和。我们比较过“先按脑区求和、再整体扣除串色”的简便算法：在示例脑片上按 12% 的串色比例试算，个别脑区的误差可达 58%（暗处像素不能扣成负数，汇总后再扣就算不准），所以没有采用。
- “分析参数”表里会写明脑区平均荧光强度是按哪种图测量的。

## 读图更快
- 读 qptiff / ome.tif / 江丰 .kfbf 时，最多用 4 个线程同时解码图块（仍在“最多用一半 CPU 核”的限制之内）；识别时相邻分块重叠的部分不再重复解码。
- 读出来的图像和以前逐像素完全相同；示例脑片细胞数仍是 DAPI+ 69348、Red+ 36701，每个细胞的位置都没有变。
- 速度：读图本身快了 2–4 倍（示例脑片随机读取 1.7 秒 → 0.4 秒；一张 198 MB 的 qptiff 按识别的分块方式读 1 GB 像素：3.6 秒 → 1.4 秒）。
- 不过在示例脑片上，读图只占细胞识别总时间的不到 1%，大部分时间花在神经网络上，所以整体识别只快了约 3%（4 核电脑：328 秒 → 319 秒）。图片越大、电脑核数越多，读图省下的时间越明显。

## v0.8.2（2026-11-14）

# v0.8.2 更新内容（小更新）

## 直接读取江丰（KFBIO）.kfbf 原始文件
- 不用先转换格式：在“① 项目与图片”和“一键批量处理”里可以直接选 .kfbf 文件，通道名、像素大小和多级分辨率都从文件里读出。
- 在一张 3 通道（DAPI / 520 / 670）测试图上核对过：3 张脑片都能自动找出来，通道颜色正确。目前只见过单层扫描、3 通道的 .kfbf，如果打不开或通道不对，请把文件发给我们。
- 分辨率较高的图片（如江丰 20x，0.33 µm/像素）自动拆分脑片从约 30 秒降到约 4 秒。

## 脑片拆分时自己指定通道
- 各通道对应哪种染色改到“② 脑片拆分”里设置：每个通道一个下拉框，可选 DAPI（AF405）、Green（AF488）、Red（AF594）、Far Red（AF647）或“不使用”，默认按扫描仪写的通道名自动猜。
- 选“不使用”的通道不识别、不显示，导出的 Excel 里也不列。两个通道不能选同一种染色。
- 每个通道旁边有“拆分”勾选框：用哪些通道找组织轮廓、拆分脑片。某个通道背景太亮、把载玻片也当成组织时，取消勾选它。
- 这些设置保存在项目里，批量处理时同一项目的图片都按这个设置。

## 识别前去除通道串色（推荐，默认开启）
- 短波长染料的荧光会有一部分“漏”进长波长通道（例如 488 漏进 647），让那个通道出现假的阳性细胞、共标数偏高。现在“④ 细胞识别”里多了“识别前去除通道串色（推荐）”，新项目默认勾选。
- 第一次识别时软件自动从图片本身估算漏进去的比例，不需要单染对照；估算后每对通道一个滑块，可以微调。比例太大会把弱的真阳性细胞也减掉，太小则去不干净。
- 取消勾选时会提示：可能把串过来的信号当成阳性细胞，共标数会偏高。
- 测试图上估出 488→647 串色 12.4%；同一块区域里 647 通道识别出的细胞从 2589 个降到 964 个（多出来的基本都是 488 阳性细胞漏过去的影子）。示例脑片（DAPI + Red）没有串色，结果不变。
- 估算的比例、是否手动调整过，都写在导出 Excel 的“分析参数”表里。只影响识别和细胞亮度；脑区平均荧光强度仍按原图测量。
- 以前的项目打开后保持“不去除串色”，原来的结果不变；需要时勾选并重新识别即可。

## 统计分析恢复到 v0.7 的速度
- v0.8 起，每次生成按脑区统计表都会按原始分辨率重读一遍原图，用来计算“脑区平均荧光强度”。“⑦ 组间统计”“脑区活动与行为相关”“功能网络”根本用不到这一项，却每次都要等。示例脑片上生成统计表从 4.0 秒变成了 9.2 秒，图片越大、越多越明显。
- 现在这三项分析不再计算荧光强度，示例脑片上回到约 3 秒，结果完全不变。
- “⑧ 导出 Excel”新增勾选框“统计每个脑区的平均荧光强度（较慢）”，默认不勾选；需要比较脑区整体亮度时再勾选。勾选后算过一次的结果会保存下来，配准、排除区域、脑片方框都没改时，再次导出不用重新读图（示例脑片 9.4 秒 → 3.5 秒），数值与重新计算完全相同。
- 一键批量处理结束时自动导出的 Excel 也按这个勾选框决定是否计算荧光强度。

## 去卷积提示
- “④ 细胞识别”各通道的“识别前去卷积”下方加了提示：勾选会增加运行时间（示例脑片多用 30–45% 的时间），但提高识别精度。
- 厚切片推荐参数仍默认勾选去卷积，薄切片默认不勾选。

## v0.8.1（2026-11-14）

# v0.8.1 更新内容（小更新）

## 软件改名：FosMap 脑片活动图谱
- 原名“cFos 脑片分析”。窗口标题、关于页、启动画面换成新名称和新图标（活动热图点阵）。
- 安装位置、项目文件和以前的结果都不受影响，照常打开。
- 桌面和开始菜单的快捷方式图标会在下次安装完整安装包时更新。

## 新功能
- 质量检查新增“阳性细胞落在白质/脑室 %”：c-Fos、NeuN 等标记物通道（不算 DAPI）的阳性细胞落在图谱白质或脑室里的比例超过 5% 时，提示这张脑片可能配歪了。这样能发现轮廓看着对、但前后位置配错的脑片。
- “⑦ 分组与统计”新增“脑区活动与行为相关”：分组表多了“行为分数”列（每只动物一个数，例如冻结时间 %），逐个脑区计算 c-Fos 密度与行为分数的 Spearman 相关，做 FDR 校正并给出 95% 置信区间，输出排序表、相关系数图和散点图。动物少于 8 只时结果会不稳定，软件会提醒。

## 更快、更省内存
- 打开项目、读取识别结果更快：示例脑片从 4.6 秒降到 0.5 秒，占用内存从 246 MB 降到 37 MB，结果文件小约 40%。共标判断从 9.9 秒降到 4.3 秒，结果完全相同。旧项目照常打开，第一次保存时自动转换为新格式。
- 质量检查改为分块读图，峰值内存从约 1 GB 降到约 0.4 GB，8 GB 内存的电脑批量检查不容易卡住。结果与原来逐位相同。
- 细胞识别和图谱自动定位（DeepSlice）不再加载 TensorFlow，直接用 ONNX 模型计算，启动更快、内存更少（示例脑片 DeepSlice 定位从 4.6 秒降到 1.2 秒）。逐个细胞的识别结果与原来完全相同，DeepSlice 定位的最大差别是 0.0001 个体素（约 2.5 纳米）。
  - 通过补丁升级时，细胞识别马上换成新方式；DeepSlice 的新模型文件较大（约 190 MB）不放进补丁，装下一个完整安装包后才换过去，在那之前照原来的方式计算，结果相同。
- 以后的完整安装包会因此不再带 TensorFlow，预计小 200 MB 以上（下次打包时实测）。“微调模型”功能保留，界面和用法都不变：第一次点“开始训练”时，软件会自动下载训练用的组件，带进度条，断网后可以接着下载，下载后会校验并自检。没有网络的电脑可以用“帮助 → 安装微调组件（离线包）”安装。现在已经安装的软件里本来就有这些组件，不需要下载。
