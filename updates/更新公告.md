# FosMap 脑片活动图谱 更新公告（原名 cFos 脑片分析）

## v0.8.1（2026-11-14）

# v0.8.1 更新内容（小更新）

## 软件改名：FosMap 脑片活动图谱
- 原名“cFos 脑片分析”。窗口标题、关于页、启动画面换成新名称和新图标（活动热图点阵）。
- 安装位置、项目文件和以前的结果都不受影响，照常打开。
- 桌面和开始菜单的快捷方式图标会在下次安装完整安装包时更新。

## 新功能
- 质量检查新增“阳性细胞落在白质/脑室 %”：c-Fos、NeuN 等标记物通道（不算 DAPI）的阳性细胞落在图谱白质或脑室里的比例超过 5% 时，提示这张脑片可能配歪了。这样能发现轮廓看着对、但前后位置配错的脑片。
- “⑦ 分组与统计”新增“脑区活动与行为相关”：分组表多了“行为分数”列（每只动物一个数，例如冻结时间 %），逐个脑区计算 c-Fos 密度与行为分数的 Spearman 相关，做 FDR 校正并给出 95% 置信区间，输出排序表、相关系数图和散点图。动物少于 8 只时结果会不稳定，软件会提醒。

## 更快、更省内存
- 打开项目、读取识别结果更快：示例脑片从 4.6 秒降到 0.5 秒，占用内存从 246 MB 降到 37 MB，结果文件小约 40%。共标判断从 9.9 秒降到 4.3 秒，结果完全相同。旧项目照常打开，第一次保存时自动转换为新格式。
- 质量检查改为分块读图，峰值内存从约 1 GB 降到约 0.4 GB，8 GB 内存的电脑批量检查不容易卡住。结果与原来逐位相同。
- 细胞识别和图谱自动定位（DeepSlice）不再加载 TensorFlow，直接用 ONNX 模型计算，启动更快、内存更少（示例脑片 DeepSlice 定位从 4.6 秒降到 1.2 秒）。逐个细胞的识别结果与原来完全相同，DeepSlice 定位的最大差别是 0.0001 个体素（约 2.5 纳米）。
  - 通过补丁升级时，细胞识别马上换成新方式；DeepSlice 的新模型文件较大（约 190 MB）不放进补丁，装下一个完整安装包后才换过去，在那之前照原来的方式计算，结果相同。
- 以后的完整安装包会因此不再带 TensorFlow，预计小 200 MB 以上（下次打包时实测）。“微调模型”功能保留，界面和用法都不变：第一次点“开始训练”时，软件会自动下载训练用的组件，带进度条，断网后可以接着下载，下载后会校验并自检。没有网络的电脑可以用“帮助 → 安装微调组件（离线包）”安装。现在已经安装的软件里本来就有这些组件，不需要下载。

## v0.8（2026-11-13）

# v0.8 更新内容

- 软件更新改为补丁包：以后只需下载约 1 MB 的补丁，不用再下载完整安装包。软件启动时会自动检查更新并显示更新公告，点“现在更新”即可；也可以在 GitHub 手动下载补丁，用“帮助 → 从文件安装补丁”安装。
- 厚切片：选择“厚切片”推荐参数时，所有通道默认勾选“识别前去卷积”，并弹窗说明。去卷积只用于找细胞，亮度测量仍用原图。
- 导出 Excel：“按脑区×脑片”新增各通道的平均荧光强度（原始灰度值，按原图分辨率测量，不含排除区域），以及相对整张脑片的比值；自定义区域也有平均荧光强度。没有阳性细胞的脑区现在也会列出（细胞数为 0）。
- 新增“帮助 → 关于”：软件功能介绍和联系方式。
- GitHub 上新增第三方组件清单（THIRD_PARTY_LICENSES.md），列出所有软件包、模型、数据的版本、许可和来源。
- 窗口标题显示当前版本。
- 完整安装包小了约 80 MB（精简了 DeepSlice 用不到的预训练权重，结果不变）。
