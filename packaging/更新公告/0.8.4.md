# v0.8.4 更新内容（小更新）

## 可以直接打开奥林巴斯 .vsi 图片
- “① 项目与图片”里加入图片、“一键批量处理”、换电脑后“找回原图”，现在都认 .vsi，不用先在 cellSens / OlyVIA 里另存为 TIFF。不需要安装 Java 或其他软件。
- 适用于奥林巴斯 / Evident 的 cellSens 显微镜软件和 VS120、VS200 玻片扫描仪保存的多通道荧光图，8 位和 16 位都支持。
- 通道名、像素尺寸（µm/像素）直接从文件里读。通道名里有染料或波长（DAPI、FITC、Cy3、Cy5、488、647 等）时自动认出 DAPI / Green / Red / Far Red；名字里看不出来时，软件会把文件里记录的发射波长写进通道名（如“通道 2 520nm”），照样能自动认出。
- z-stack 按“① 项目与图片”里选的合成方式读取（最大投影、景深合成、平均投影），和 OME-TIFF 的 z-stack 用法一样；单层扫描和扫描仪已做景深合成（EFI）的图直接读。
- 一个 .vsi 里有多幅图时（标签、预览图、主扫描图），软件自动使用最大的那幅主扫描图，并在加入图片时提示用的是哪一幅。

## 使用 .vsi 时要注意
- **.vsi 和同名的“_名字_”文件夹必须放在一起。** 例如“片子1.vsi”旁边要有“_片子1_”文件夹。.vsi 本身只有几百 KB，只存说明信息；真正的图像在这个文件夹里的 .ets 文件中。拷贝、移动图片时要把两者一起拷，只拷 .vsi 会提示“没有找到像素文件夹”。
- 加入图片时选 .vsi，不要选 .ets。
- 明场（HE 等 RGB 彩色）扫描不支持，本软件只分析荧光图。
- 时间序列只使用第 1 个时间点。

## 验证情况
- 用公开的 cellSens 样本（2 通道 × 11 层 z-stack，16 位，JPEG 2000 压缩）核对过：读出的像素与另外两个独立的读取程序（slideio、bioio-vsi）逐像素相同，通道名和像素尺寸一致。
- 不压缩、JPEG 压缩、多层金字塔、拼接扫描、缺失图块这几种情况用按格式生成的测试文件核对过。
- 还没有在 VS120 / VS200 玻片扫描仪的真实荧光文件上试过。如果某个 .vsi 打不开或图像不对，请把 .vsi 和“_名字_”文件夹发给我们。

## 一次就能更新到最新版
- 补丁里装的是当时最新的整套程序。不管电脑上是 v0.8 还是 v0.8.1 – v0.8.3，点“帮助 → 检查更新”都会直接升到 v0.8.4。
- v0.7 没有自动更新功能：下载补丁 zip，解压后双击里面的“手动安装”脚本即可（Windows 用 .bat，Mac 用 .command）。
- 这次只改了程序代码，不需要重新下载完整安装包。
