# v0.8.2 更新内容（小更新）

## 直接读取江丰（KFBIO）.kfbf 原始文件
- 不用先转换格式：在“① 项目与图片”和“一键批量处理”里可以直接选 .kfbf 文件，通道名、像素大小和多级分辨率都从文件里读出。
- 在一张 3 通道（DAPI / 520 / 670）测试图上核对过：3 张脑片都能自动找出来，通道颜色正确。目前只见过单层扫描、3 通道的 .kfbf，如果打不开或通道不对，请把文件发给我们。
- 分辨率较高的图片（如江丰 20x，0.33 µm/像素）自动拆分脑片从约 30 秒降到约 4 秒。

## 脑片拆分时自己指定通道
- 各通道对应哪种染色改到“② 脑片拆分”里设置：每个通道一个下拉框，可选 DAPI（AF405）、Green（AF488）、Red（AF594）、Far Red（AF647）或“不使用”，默认按扫描仪写的通道名自动猜。
- 选“不使用”的通道不识别、不显示，导出的 Excel 里也不列。两个通道不能选同一种染色。
- 每个通道旁边有“拆分”勾选框：用哪些通道找组织轮廓、拆分脑片。某个通道背景太亮、把载玻片也当成组织时，取消勾选它。
- 这些设置保存在项目里，批量处理时同一项目的图片都按这个设置。

## 识别前去除通道串色（推荐，默认开启）
- 短波长染料的荧光会有一部分“漏”进长波长通道（例如 488 漏进 647），让那个通道出现假的阳性细胞、共标数偏高。现在“④ 细胞识别”里多了“识别前去除通道串色（推荐）”，新项目默认勾选。
- 第一次识别时软件自动从图片本身估算漏进去的比例，不需要单染对照；估算后每对通道一个滑块，可以微调。比例太大会把弱的真阳性细胞也减掉，太小则去不干净。
- 取消勾选时会提示：可能把串过来的信号当成阳性细胞，共标数会偏高。
- 测试图上估出 488→647 串色 12.4%；同一块区域里 647 通道识别出的细胞从 2589 个降到 964 个（多出来的基本都是 488 阳性细胞漏过去的影子）。示例脑片（DAPI + Red）没有串色，结果不变。
- 估算的比例、是否手动调整过，都写在导出 Excel 的“分析参数”表里。只影响识别和细胞亮度；脑区平均荧光强度仍按原图测量。
- 以前的项目打开后保持“不去除串色”，原来的结果不变；需要时勾选并重新识别即可。

## 统计分析恢复到 v0.7 的速度
- v0.8 起，每次生成按脑区统计表都会按原始分辨率重读一遍原图，用来计算“脑区平均荧光强度”。“⑦ 组间统计”“脑区活动与行为相关”“功能网络”根本用不到这一项，却每次都要等。示例脑片上生成统计表从 4.0 秒变成了 9.2 秒，图片越大、越多越明显。
- 现在这三项分析不再计算荧光强度，示例脑片上回到约 3 秒，结果完全不变。
- “⑧ 导出 Excel”新增勾选框“统计每个脑区的平均荧光强度（较慢）”，默认不勾选；需要比较脑区整体亮度时再勾选。勾选后算过一次的结果会保存下来，配准、排除区域、脑片方框都没改时，再次导出不用重新读图（示例脑片 9.4 秒 → 3.5 秒），数值与重新计算完全相同。
- 一键批量处理结束时自动导出的 Excel 也按这个勾选框决定是否计算荧光强度。

## 去卷积提示
- “④ 细胞识别”各通道的“识别前去卷积”下方加了提示：勾选会增加运行时间（示例脑片多用 30–45% 的时间），但提高识别精度。
- 厚切片推荐参数仍默认勾选去卷积，薄切片默认不勾选。

## 一次就能更新到最新版
- 补丁里装的是当时最新的整套程序，不是只装和上一版的差别。不管电脑上是 v0.8 还是 v0.8.1，点“检查更新”都会直接升到最新版，不用一个一个装。
