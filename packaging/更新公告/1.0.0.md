# FosFolio 脑片图册 v1.0.0

本版面向 Windows x64 和 Apple 芯片 Mac，包含 v0.9.22 的累计功能及以下修复。

- **共标统计**　修复复用旧识别缓存时出现 `'float' object has no attribute 'hypot'` 并跳过整张图片的问题。遇到过此错误的用户可在「细胞识别」中选择先前失败的图片，用原参数再次运行。软件会复用匹配的脑片缓存并补算共标。
- **旋转后拖动视野**　脑片旋转后，鼠标左键拖动遵循当前屏幕方向。连续平移和缩放后也能跟随指针。
- **细胞预览**　大量细胞显示时，缩放可跳过空选区的高亮刷新，鼠标定位使用空间索引查找附近细胞。细胞标记的大小、位置和手动校正仍沿用原有规则。

## 安装和升级

1. 已经安装 v0.9.x 的 Windows 和 Mac 用户请保存项目，在「帮助 → 检查更新」中选择「现在更新」，然后重启。补丁复用已安装的运行环境和模型。较早的客户端若先收到 v0.9.22，请重启后再检查一次。
2. 首次安装 Windows x64 版时，解压腾讯云完整 ZIP 并保留所有分卷，或从 GitHub 将 Setup.exe、-1.bin 和 -2.bin 下载到同一文件夹，再运行 Setup.exe。
3. 首次安装 Apple 芯片 Mac 版时，解压 `FosFolio-1.0.0-macOS-arm64-Offline-Compact.tar.xz`，将应用拖入「应用程序」。

离线安装包内含 Cellpose 4 运行环境和模型。国内下载优先使用[腾讯云 CNB 发布页](https://cnb.cool/fosfolio/cfos-brain-slice/-/releases/tag/v1.0.0)，也可以使用 [GitHub Release](https://github.com/zjm199502/cfos-brain-slice/releases/tag/v1.0.0)。
