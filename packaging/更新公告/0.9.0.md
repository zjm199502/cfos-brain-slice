# FosFolio 脑片图册 v0.9.0

这是 v0.8 之后的完整安装版，包含此前通过软件内更新发布的改进。

## 安装与首次识别

- Windows x64 用户下载并运行 [Windows 安装程序](https://github.com/zjm199502/cfos-brain-slice/releases/download/v0.9.0/FosFolio-0.9.0-Windows-x64-Setup.exe)。Apple 芯片 Mac 用户下载并解压 [macOS arm64 安装包](https://github.com/zjm199502/cfos-brain-slice/releases/download/v0.9.0/FosFolio-0.9.0-macOS-arm64.zip)，将应用拖入“应用程序”。升级前请退出正在运行的 FosFolio。
- 首次识别前，在「④ 细胞识别」点「安装 / 修复 Cellpose 4 运行环境」。这一步需要联网并预留数 GB 磁盘空间，其中模型约 1.23 GB。安装完成后可以离线识别。
- 点「测试 Cellpose 设备」可查看显卡型号和实际推理设备。支持兼容 NVIDIA 显卡的 CUDA、Apple 芯片的 PyTorch MPS（Metal）以及 CPU。需要固定使用 CPU 时可选「仅 CPU」。

## 细胞识别与单层厚切片

- DAPI、EGFP、Fos 等所有启用的通道均独立使用 Cellpose 4.2.1 和 Cellpose-SAM v2 模型（`cpsam_v2`）生成轮廓。每个通道可以单独设置掩膜阈值、面积和阳性强度筛选条件。
- 可在一张玻片中勾选一张或多张脑片识别，稍后补做其余脑片。对弱信号或背景不均的单层厚切片，可先标出代表性视野中的阳性细胞，用同一组人工标注比较参数的命中、漏检和误检，再应用到当前脑片的当前通道。项目和 Excel 会记录评估结果。
- 已拆分脑片的视野预览与整片使用相同的亮度归一化、组织轮廓和分块边界。盲评中只调整局部对比度时可以复用同一批候选细胞。
- 旧项目可继续打开并查看原有计数。重新识别会为所选脑片生成 Cellpose 结果。旧版 StarDist 自训练权重和概率阈值仅适用于原模型。跨版本比较前，可用已标注视野复核新模型的计数差异。

## 导出、项目与显示

- Excel 的「按脑区×脑片」默认导出左右合计，也可选单侧、分侧，或分侧并附合计。项目会记住选择，工作簿「分析参数」会注明导出方式。
- 选片窗口、质控图和 Excel 区分未分析与已分析但零细胞。未分析脑片的计数留空，已分析的零细胞脑片导出全零掩膜。逐片重新筛选时，缺少原始候选缓存的脑片会保留已有细胞并标明「沿用上次结果」。
- Excel 计数汇总可以复用已保存的完整细胞结果，减少内存占用。修复了部分 QPTIFF 缩略层索引不全导致拆片报错的问题；窄屏上的步骤、图层、设置和教学说明均可滚动或切换查看。
