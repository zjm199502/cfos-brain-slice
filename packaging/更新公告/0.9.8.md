# FosFolio v0.9.8 蔡司 CZI 导入更新

在「① 项目与图片 → 添加图片」中，可选择「蔡司 ZEN 图像」来筛选 `.czi` 和 `.CZI` 文件。选中一份多场景文件后，各场景会分别出现在项目中，可独立预览和分析。

部分 CZI 文件含有未标记的低分辨率缩略图，旧版会在导入时提示无法确认原始像素。本版会核对缩略图覆盖的范围。只要同一场景、通道、Z 层和采集时间的原始图块完整覆盖该区域，即可导入，并按原始像素拼接和分析。原始数据缺失时，软件会提示重新导出。

适用于带 X/Y 等距像素标定的单文件、8 位或 16 位灰度荧光图像。可读取多通道、拼接和 Z 层。时间序列按首个采集时间点分析。多文件分卷或 RGB 明场图像目前仍需先在 ZEN 中转换。

Windows 和 macOS 的 v0.9.x 用户均可在「帮助 → 检查更新」安装本补丁，然后重启软件。若先收到过渡版本，重启后再次检查更新。
