# FosFolio 脑片图册 v1.0.2

本版是软件内补丁。主要有两项改动：大项目不再卡顿；每个步骤页都可以清除本步的结果后重新分析。

- **清除本步结果，重新分析**　每个步骤页底部新增“重新分析”框。框里先用一行字说明在这一步重新分析时旧结果会怎样处理，下面是“清除所选范围的…结果”按钮，按本页选择的处理范围（整张图片或指定脑片）清除。点按钮后先弹出确认框，列出将删除的内容和之后需要重做的步骤，确认后才删除，默认按钮是“取消”。
  - ① 项目：清除全部分析结果，图片保留，可以从 ② 重新开始。
  - ② 脑片拆分：清除脑片轮廓，以及这些脑片的识别、人工修正、配准、分组和单独设置的亮度。
  - ③ 亮度 / 对比度：图片或脑片单独设置的亮度恢复为项目设置。
  - ④ 细胞识别：清除细胞结果和原始识别缓存。之前参数没变时，重新识别会直接沿用上次的结果；清除后再识别会真正重新计算。人工补加 / 删除的细胞默认保留，也可以勾选一并清除。
  - ⑤ 共标：只清除共标结果，识别结果保留。
  - ⑥ 配准：清除当前图谱的配准结果（包括手动调整和标志点）及相应的位移场文件；另一图谱的结果不受影响。
  - ⑦ 分组：清除动物编号和组别；可以勾选一并删除项目文件夹中以往的统计结果文件夹。
  - ⑧ 导出 / ⑨ 制图：清除导出和制图记录（以及截图框）；已经保存的 Excel 和图片文件不会删除。

  清除后，后续步骤的“曾参与统计 / 曾导出 / 曾制图”记录会一并去掉，项目页会显示哪些步骤需要重做。
- **大项目更流畅**　进入 ⑤ 共标统计页时，汇总表在后台计算，不再卡住界面，内存中只保留最近查看的 4 张图片的细胞结果。频繁的小改动（改名、勾选、调整设置等）合并后在后台保存，项目文件也写得更紧凑。分组表编辑时不再复制整个项目。项目页的逐脑片进度只读很小的索引文件，不再读取完整的识别缓存。图片列表不再反复检查原图是否存在。

## 安装和升级

已经是 v1.0.0 或 v1.0.1 的 Windows 和 Apple 芯片 Mac 用户（包括从 v0.9 通过软件内更新升上来的）：请先保存项目，在「帮助 → 检查更新」中选择「现在更新」，然后重启软件。补丁复用已安装的运行环境和模型，已有项目可以继续使用，已有结果不会因为升级而改变。
