# FosFolio v0.8.7 更新公告

## 每张脑片可以先盲评，再决定识别参数

在「④ 细胞识别」中选择通道，在已拆分脑片内放置检查框，点出人工判断的阳性细胞。即使还没有做整图识别，也可以先比较参数。清楚且没有阳性的视野可作为阴性对照。

锁定人工点后，软件在同一视野比较当前与候选的局部对比度、去卷积设置。结果显示命中、误检、漏检、F1、差异轮廓和新增候选的人工确认数。阴性视野还显示每平方毫米误检数。相同参数下可汇总多个视野，重复检查同一个框取最近一次。

选择「应用」会将设置保存到当前脑片的当前通道，并重新识别当前图片。预览、单张识别、批处理和重新筛选均支持脑片专属设置。可在「本图盲评记录与脑片参数」查看记录、恢复本图的项目参数。项目保留人工点和当时的选择；导出 Excel 时新增「脑片盲评」表。

## 单层厚片和大图读取

修复部分 EFI 导出文件中通道名称显示为「通道1/2/3」的问题。新导入图片时可读取带 XML 命名空间的 OME 通道标签，例如 DAPI、FITC 和 Cy5。厚片用户可先在弱阳性和阴性组织中比较局部对比度 1.5 与 1.3，同时检查去卷积对本张脑片的影响，再选择参数。

大幅单层 TIFF 可分带生成组织缩略图；满足条件的 8 位、16 位无符号图像也可分带计算归一化百分位数，降低整幅图像同时驻留内存的需求。

## 升级方式

v0.8 及以上用户打开「帮助 → 检查更新」，安装后重启。如已下载补丁 ZIP，可选择「帮助 → 从文件安装补丁」。本次是累计软件内补丁，包含此前发布的 FosFolio 名称与图标、同名图片结果隔离、零计数脑区和密度修正、弱阳性漏检追踪及缓存优化。
